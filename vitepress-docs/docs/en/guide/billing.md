# Billing & Wallet

This feature allows users to top up coins and use them for premium services.

## Wallet
Users can view their coin balance and transaction history in the Wallet page.
Coins are used for:
- Creating custom email addresses (if enabled).
- Premium domain usage.

## Top-up
We support multiple payment channels through Xendit (IDR).
- QRIS
- Bank Transfer (Virtual Account)
- E-Wallets (OVO, Dana, LinkAja)

## Ledger
All coin movements are recorded in the Ledger.
- `TOPUP`: Coins added from successful payment.
- `BONUS`: Extra coins awarded for large top-ups.
- `DEBIT`: Coins spent on services.
